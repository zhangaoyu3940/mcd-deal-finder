# 贡献者行为准则

## 我们的承诺

为了营造开放友好的环境，我们作为贡献者和维护者承诺：
不以任何方式骚扰他人、参与攻击性言论、
滋扰社区或以其他任何方式对他人施加负面影响的言行。

## 我们的标准

有助于营造正面环境的行为包括：

- 使用友善和包容的语言
- 尊重不同的观点和经验
- 优雅地接受建设性批评
- 关注对社区最有利的事情
- 对错误表示同理心

不可接受的行为包括：

- 与主题无关的性化语言或图像，以及不受欢迎的关注或调戏
- 挑衅、侮辱/贬损的评论，人身攻击或政治攻击
- 公开或私下的骚扰
- 未经明确许可，发布他人的私人信息
- 在专业场合被认为不恰当的其他行为

## 项目特有约定

本项目涉及商业品牌与价格数据，请额外遵守：

1. **不提交真实用户数据** — 包括门店地址、卡包券、订单记录、账号 ID 等。
2. **不承诺价格准确性** — 提交内容中不要出现「保证最省」「一定省钱」等表述。
3. **不夹带商业推广** — 本项目非商业性质，PR 中不得植入无关推广。
4. **尊重商标边界** — 文档中使用「麦当劳」等商标仅为说明兼容目标，
   不得设计可能造成官方关联暗示的 Logo 或素材。

## 适用范围

本准则适用于项目所有空间：Issue、PR、讨论、提交信息，
以及个人代表项目发言的其他场合。

## 强制执行

维护者有权根据其判断采取适当的纠正措施，
包括但不限于：警告、封禁提交、永久或临时禁止任何形式的公开交流。

## 归属

本准则改编自
[Contributor Covenant](https://www.contributor-covenant.org/) 2.1 版本，
并增加了本项目特有的数据与商标约定。
